# Almost a Circle - But Not Quite! 🔵⬛

## What's This All About?

Welcome to my journey of making shapes that are *almost* a circle! 🎯

This project is where geometry meets Python OOP, and honestly? It's been quite the ride. We're building rectangles and squares (because who needs actual circles anyway?) with all the fancy OOP stuff - inheritance, JSON serialization, and enough unit tests to make your head spin.

## The Vibe

Think of this as:
- 📐 Shapes that actually know their dimensions (no more guessing!)
- 🎨 Pretty printed displays with '#' characters (because why not)
- 💾 Save and load your shapes like a boss
- 🧪 Tests that probably hate me but I love them
